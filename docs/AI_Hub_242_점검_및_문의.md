### 필요한 파일 (👤 AI Hub 다운로드 창에서 "선택 다운로드")
**1차 (구조 확인용, 약 100MB)**
- `Training/[라벨]음식001_Tra_json.zip`
- `Info Table/통합 식품영양성분DB.zip`

**2차 (1차에서 박스가 확인되면, 음식별 수량용)**
- `[라벨]`로 시작하는 zip **전부** (Training + Validation). **사진(원천) zip은 받지 않음**
- 파일 이름이 `음식001`, `음식002`… 로 나뉘어 있어서, zip 하나에 음식 일부만 들어 있을 가능성이 큼 → 음식별 수량은 라벨 zip을 다 봐야 정확함

### 실행 방법 (👤, Python 없이)
1. `check_labels.bat`, `check_labels.ps1`을 같은 폴더에 둠
2. 받은 zip을 `check_labels.bat` 위에 끌어다 놓음 (여러 개 한 번에 가능, 압축 풀 필요 없음)
3. 파란 경고창 → "추가 정보 → 실행"
4. 자동으로 열리는 `result_send_me.txt` 내용을 복사해서 채팅에 붙임

- zip 안을 **읽기만** 함. 원본을 바꾸거나 다른 곳으로 보내지 않음
- 결과 파일에는 라벨 글자 요약만 들어감 (사진 없음)
- zip 하나당 JSON 앞 3,000개만 읽음 (속도 때문). 결과에 "샘플 기준"이라고 표시됨
  → 구조를 확인한 뒤 키 이름에 맞춘 **빠른 전체 개수 세기 도구**를 따로 만들 예정

## 허용되지 않을 때 대안

| 대안 | 내용 | 비용·부담 | 메모 |
|---|---|---|---|
| A. 한식 = 직접 찍은 사진 | 한식 4종을 직접 촬영 + 라벨링 (클래스당 80~150장) | 시간 많이 듦 | 내 데이터라 제약 없음. 평가용 100장과는 **따로** 찍어야 함 |
| B. 국내 학습 환경 | 학교 GPU 서버·실습실, 국내 클라우드 GPU | 학교면 무료, 클라우드는 시간당 유료 | 👤 학교/지도교수님께 GPU 서버 있는지 먼저 문의 추천 |
| C. 해외 사용이 허용된 공개 데이터 | Open Images(CC BY), 연구용 공개 음식 데이터 | 무료 | 한식이 거의 없음 → A와 섞어야 함. 각 데이터 약관 확인 필수 |
| D. 내 PC에서 소규모 학습 | n 모델, 작은 이미지, 적은 epoch, CPU | 무료, 느림 | 사용자가 원치 않은 방식 → **마지막 수단** |

추천 순서: **답변 기다리는 동안 B(학교 GPU) 문의를 같이 넣기** → 안 되면 A + C.
