# 갤럭시 앱 빌드 · 설치 · 실기기 테스트 가이드

처음 하는 사람도 순서대로 따라 하면 된다. 막히면 그 단계 번호랑 화면 캡처를 보내 주면 된다.

> ⚠️ 아직 **진짜 갤럭시에서 확인한 기능은 없음**. 아래 체크리스트를 하나씩 확인하면서 결과를 알려 주면 된다.

---

## 0. 준비물 (처음 한 번)

1. **PC** (윈도우 또는 맥). 저장 공간 15GB 이상 남아 있으면 좋음
2. **갤럭시 폰**과 **USB 케이블** (충전만 되는 케이블 말고 데이터 되는 것)
3. **Node.js 22** 설치: https://nodejs.org → LTS 버전 받아서 계속 '다음'
4. **Git** 설치: https://git-scm.com → 계속 '다음'
5. **Android Studio** 설치: https://developer.android.com/studio → 설치 후 처음 실행하면 나오는 'Standard' 설정 그대로 '다음'
   - 처음 실행 때 Android SDK 를 자동으로 내려받음 (10~20분)

## 1. 코드 받기 (처음 한 번)

PC 에서 **터미널**(윈도우: 시작 메뉴에서 'PowerShell', 맥: 'Terminal')을 연다.

```bash
git clone https://github.com/ybxxyb5959-droid/slimlog.git
```

```bash
cd slimlog
```

```bash
git checkout claude/confident-albattani-boohj6
```

## 2. 열쇠 파일 만들기 (처음 한 번)

`slimlog` 폴더 안에 `.env.production.local` 이라는 파일을 만들고 아래 두 줄을 넣는다. 값은 Supabase → Project Settings → API 화면에 있음.

```
VITE_SUPABASE_URL=https://프로젝트주소.supabase.co
VITE_SUPABASE_ANON_KEY=anon 키
```

- anon 키는 원래 공개되는 키라 앱에 들어가도 됨
- **service_role 키는 절대 넣지 말 것** (서버 전용)
- 서버(FastAPI)를 배포했으면 `VITE_API_URL=https://서버주소` 도 한 줄 추가

## 3. Supabase 에 앱 주소 등록 (처음 한 번)

Supabase → **Authentication → URL Configuration → Redirect URLs** 에 아래 주소를 추가하고 Save.

```
com.slimlog.app://auth-callback
```

이게 없으면 갤럭시 앱에서 카카오·구글 로그인 후 앱으로 돌아오지 못한다.

## 4. 빌드해서 폰에 설치

### 4-1. 웹 화면 만들고 안드로이드 프로젝트에 복사

```bash
npm install
```

```bash
npm run cap:sync
```

- `npm install` 할 때 지문 플러그인 보안 패치(`patches/`)가 자동으로 적용된다. 끝에 `patch-package` 줄이 보이면 정상

### 4-2. 폰 준비 (처음 한 번)

1. 폰 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 연속 톡톡 → "개발자 모드를 켰습니다"
2. **설정 → 개발자 옵션 → USB 디버깅** 켜기
3. USB 로 PC 에 연결 → 폰에 "USB 디버깅을 허용할까요?" 뜨면 **허용**

### 4-3. Android Studio 로 설치

```bash
npm run cap:open
```

1. Android Studio 가 열리면 아래쪽 진행바(Gradle sync)가 끝날 때까지 기다림 (처음엔 5~10분)
2. 위쪽 기기 선택 칸에 내 갤럭시 이름이 보이는지 확인
3. 초록색 ▶ (Run) 버튼 클릭 → 폰에 SlimLog 가 설치되고 바로 열림

### 4-4. APK 파일로 뽑기 (다른 폰에 보낼 때)

Android Studio 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)** → 끝나면 오른쪽 아래 'locate' 클릭 → `app-debug.apk`

- 이건 테스트용(debug) APK. 플레이스토어용 서명 빌드는 나중 단계

### 코드가 바뀌었을 때

```bash
git pull
```

```bash
npm install
```

```bash
npm run cap:sync
```

그다음 Android Studio 에서 ▶ 다시 누르기.

## 5. 실기기 테스트 체크리스트

결과는 ✅ / ❌ 로 표시해서 알려 주면 된다. ❌ 면 어떤 화면에서 어떻게 됐는지 한 줄 + 캡처(눈바디 화면은 캡처가 막혀 있으니 말로).

### A. 설치·기본
- [ ] A1. 앱 이름이 **SlimLog** 로 설치된다
- [ ] A2. 앱을 열면 스플래시 → 로그인 화면이 뜬다
- [ ] A3. 다크 모드 폰이면 앱도 어둡게 보인다 (설정 → 화면 밝기에서 바꿔도 됨)
- [ ] A4. 폰 뒤로 가기 버튼이 이전 화면으로 간다

### B. 로그인
- [ ] B1. 카카오 로그인 → 브라우저(크롬 탭)가 열린다 → 로그인 → **SlimLog 앱으로 돌아와서** 동의/홈 화면
- [ ] B2. 구글 로그인 → 같은 흐름 (웹뷰가 아니라 크롬 탭이라 구글이 막지 않아야 함)
- [ ] B3. 앱을 완전히 끄고(최근 앱에서 밀기) 다시 열면 로그인이 유지된다

### C. 눈바디 잠금 · 지문
- [ ] C1. 눈바디 처음 → 안내 문구 → 비밀번호 만들기 → **복구 코드 24자리**가 보인다 → 종이에 적기 → 체크 → 확인
- [ ] C2. 카메라로 정면 사진 등록 → 사진이 보인다
- [ ] C3. 폰 **갤러리 앱**에 방금 찍은 눈바디 사진이 **없다**
- [ ] C4. 눈바디 화면에서 **스크린샷**을 찍으면 막힌다 ("보안 정책" 안내 등)
- [ ] C5. 눈바디 화면에서 홈 버튼 → **최근 앱 화면**에서 SlimLog 미리보기가 **검게/비어** 보인다
- [ ] C6. 다른 화면(홈·식단)에서는 스크린샷이 **된다** (눈바디만 막힘)
- [ ] C7. 눈바디 설정(⋯) → 지문 잠금 켜기 → 비밀번호 입력 → "지문 잠금을 켰어요"
- [ ] C8. 지금 잠그기 → **지문 창이 자동으로 뜬다** → 지문 → 열림
- [ ] C9. 잠근 뒤 지문 창에서 '비밀번호로 열기'(취소) → 자동으로 다시 안 뜨고 비밀번호 칸이 보인다 → '지문으로 열기' 버튼으로 다시 열 수 있다
- [ ] C10. 눈바디 화면에서 홈 버튼 → 다시 앱으로 → **잠겨 있다**
- [ ] C11. 눈바디 열어 두고 5분 동안 안 만지면 잠긴다
- [ ] C12. 앱을 완전히 끄고 다시 열기 → 눈바디 들어가면 잠금 화면(지문 자동) → 열면 **사진이 그대로 보인다**
- [ ] C13. 폰 **설정 → 생체 인식 → 지문 하나 추가 등록** → SlimLog 눈바디 → 지문으로 열기가 **실패**하고 "지문을 새로 등록했다면…" 안내 → 비밀번호로 열림 → 지문 잠금 다시 켜면 다시 됨
- [ ] C14. 지문 잠금 끄기 → 잠그기 → 지문 창 안 뜨고 비밀번호로만 열린다

### D. 비밀번호 분실 · 복구
- [ ] D1. 잠금 화면 → 비밀번호를 잊었어요 → 지문으로 열고 새 비밀번호 → 새 비밀번호로 열린다, 예전 비밀번호는 안 된다
- [ ] D2. 비밀번호를 잊었어요 → 복구 코드(C1 에서 적은 것) 입력 → 새 비밀번호 → 사진 그대로
- [ ] D3. 틀린 복구 코드 → "복구 코드가 맞지 않아요"
- [ ] D4. 설정 → 복구 코드 새로 만들기 → 예전 코드로는 안 열리고 새 코드로 열린다
- [ ] D5. 설정 → 비밀번호 변경 → 새 비밀번호로 열린다

### E. 다른 기능 영향
- [ ] E1. 식단 → 카메라로 촬영 → 사진이 보이고 다음 단계로 간다 (서버 연결 전이면 "서버 연결 후 열려요" 안내가 정상)
- [ ] E2. 식단 → 갤러리에서 선택도 된다
- [ ] E3. 인바디 결과지 사진 → 글자 읽기 → 숫자 확인 화면 (처음엔 언어 데이터 받느라 느릴 수 있음)
- [ ] E4. 투약·체중·증상·케어 기록 저장 → 앱 껐다 켜도 남아 있다 (Supabase 연결)
- [ ] E5. 영양제 알림 켜기 → "갤럭시 앱 알림은 다음 업데이트에서 지원해요" 안내 (정상, 아직 FCM 아님)

### F. 삭제·재설치 정책 (마지막에)
- [ ] F1. 앱 삭제 → 다시 설치 → 로그인은 다시 해야 하고, **눈바디 사진은 사라져 있다** (의도된 동작: 기기에만 저장, 백업 안 함)
- [ ] F2. 폰 설정 → 계정 및 백업 → 구글 백업에 SlimLog 데이터가 포함되지 않는다 (확인 가능한 경우만)

## 6. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| Android Studio 에 폰이 안 보임 | 케이블 바꾸기, 폰 화면 켜고 'USB 디버깅 허용' 다시, 폰 알림창에서 USB 모드를 '파일 전송'으로 |
| `npm` 명령을 못 찾음 | Node.js 설치 후 터미널을 껐다 다시 열기 |
| 로그인 후 앱으로 안 돌아옴 | 3번(Redirect URLs) 확인 |
| 지문 잠금 스위치가 회색 | 폰 설정에서 지문을 먼저 등록. 얼굴 인식만 있으면 안 됨 (보안 등급이 낮아서 일부러 막음) |
| 지문 잠금 켤 때 "재등록 감지를 지원하지 않을 수 있어요" | 그 폰은 지문 잠금을 쓸 수 없음 (보안 패치로 일부러 막음). 비밀번호·복구 코드로 사용 |
