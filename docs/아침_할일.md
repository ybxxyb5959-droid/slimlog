다 끝나면 채팅에 "준비 다 했어"라고만 보내 주면 된다.
**비밀번호·키는 채팅에 붙이지 말 것.** 2번과 6번은 사이트나 설정 화면에 직접 넣는다.

- supabase.com → 프로필 → **Account preferences → Access Tokens** → 어제 만든 토큰 **휴지통**
- slimlog 프로젝트 → **Project Settings → Database → Reset database password** → 새 비번은 메모장에만

## 3. 카카오 로그인 키 (10분) — ✅ 켜짐 확인 (2026-11-04)
1. developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가 (이름 `SlimLog`)
2. **앱 키 → REST API 키** 복사
3. **카카오 로그인 → 활성화 ON**
4. **Redirect URI**: `https://meuzopguteqnfvbgfpvy.supabase.co/auth/v1/callback`
5. **보안 → Client Secret → 코드 생성·사용함** → 복사
6. **동의항목**: 닉네임 켜기. 이메일은 비즈 앱이어야 켤 수 있음
7. Supabase → **Authentication → Sign In / Providers → Kakao** → 켜기 → 2번 키, 5번 Secret 붙여넣기 → Save
   - 비즈 앱 전환을 안 했으면 같은 화면의 **"이메일 없는 사용자 허용"** 옵션을 켜야 로그인이 됨

## 4. 구글 로그인 키 (10분) — ✅ 켜짐 확인 (2026-11-04)
1. console.cloud.google.com → 새 프로젝트 `SlimLog`
2. **API 및 서비스 → OAuth 동의 화면** → 외부 → 앱 이름 `SlimLog` → **테스트 사용자**에 발표 때 쓸 구글 계정 추가
3. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션**
   - 승인된 리디렉션 URI: 3번과 같은 주소
4. Supabase → Providers → **Google** → 켜기 → 클라이언트 ID·보안 비밀번호 붙여넣기 → Save

## 6. 내가 클라우드에 바로 붙을 수 있게 (5분) — ✅ 완료. 통합 30/30, 화면 16/16 통과 (`docs/DB_Supabase_설계안.md` 10절)
Claude 환경 설정(세션 제목 옆 환경 메뉴 → Edit)에서:
- **Network access → Allowed domains**에 3개 추가: `api.supabase.com`, `*.supabase.co`, `*.supabase.com`
  - Allow package managers 체크는 그대로 두기
- 환경변수(또는 Network secrets)
  - `VITE_SUPABASE_URL` = Project Settings → API 의 Project URL
  - `VITE_SUPABASE_ANON_KEY` = 같은 화면의 anon(publishable) 키 (원래 공개되는 키)
  - (선택) `SUPABASE_SERVICE_ROLE_KEY` = 같은 화면의 service_role 키 → 이게 있어야 내가 클라우드에서 로그인·사진 통합 테스트 30개를 돌리고 서버도 붙일 수 있음
- 저장하고 **새 세션**에서 "준비 다 했어"
