### 계산하는 것
- 이미지당 **전체 박스 수**와 **서로 다른 음식 클래스 수**를 따로 계산
  (예: 김치 2접시 = 박스 2개, 클래스 1종)
- 서로 다른 음식이 **2종 이상** 나오는 이미지 비율 ← 멀티라벨 판단 핵심 지표
- 클래스별 등장 이미지 수 / 박스 수, 음식 조합 빈도, 함께 나오는 음식 쌍
- `--classes 파일` 로 관심 클래스(예: 후보 20종)만 걸러서 집계, 데이터에 없는 클래스 경고

### 예외 처리
- 잘못된 JSON → 멈추지 않고 `invalid_json` 으로 기록
- 라벨 객체를 못 찾은 파일 → `no_annotations`
- 박스는 있는데 클래스 이름이 빈 객체 → `클래스 이름 없는 객체` 로 따로 셈
- 중복 이미지 ID → 목록 출력, 기본은 처음 것만 사용 (`--dup-policy merge` 로 합치기 가능)
- UTF-8 BOM 파일 대응
- 읽은 라벨이 0개면 **통계를 만들지 않고** 종료 (가짜 0% 같은 숫자 출력 안 함)
- 결과 폴더(`--out-dir`)가 데이터 폴더 안이면 거부 → 원본 폴더에 아무것도 쓰지 않음

### 스키마가 달라도 대응하는 방법
라벨 추출을 집계와 분리했다. 추출기만 바꾸면 된다.
- `auto` (기본): COCO 형식이면 `coco`, 아니면 `generic`
- `coco`: `images / annotations / categories`
- `generic`: JSON 트리에서 "클래스 이름 키가 있는 dict" 를 박스로 모음.
  키 이름을 모르면 `--class-key 음식명 --image-key 파일명` 처럼 지정
- 새 스키마가 확인되면 `EXTRACTORS` 에 함수 하나만 추가

### 실행 예
```bash
python3 ai/scripts/inspect_labels.py --root /안심존/라벨폴더 --classes ai/classes_candidate.txt --out-dir ./report
```
결과: 화면 요약 + `label_report.json`, `class_counts.csv`, `combo_counts.csv`

## 3. AI Hub 71392 (당뇨관리 앱 음식 이미지) — 안심존 접근 제약

공식 페이지에 **"온라인 안심존" 데이터**로 표시되어 있다고 확인받음. 그래서 아래를 **가정하지 않는다.**

| 항목 | 현재 판단 |
|---|---|
| 일반 다운로드 | **가능하다고 가정하지 않음** |
| 원본을 이 저장소·클라우드·Colab·개인 PC 로 복사 | **하지 않음** |
| 안심존 안에서 JSON 열람 | **확인 필요** |
| 안심존 안에서 Python 스크립트 실행 (inspect_labels.py) | **확인 필요** — 표준 라이브러리만 쓰므로 Python 만 있으면 됨 |
| 안심존 안에서 PyTorch 학습 (CPU/GPU 제공 여부) | **확인 필요** |
| 학습된 모델 가중치(.pt/.onnx)를 밖으로 반출 | **확인 필요** — 반출 심사 대상일 가능성 높음 |
| 집계 결과(클래스별 개수 CSV)만 반출 | **확인 필요** |
| 이미지당 음식 여러 개 + 박스 라벨 여부 | **확인 필요** (소개 자료상 bbox JSON 이 있다고 하나 직접 보지 못함) |

### 확인할 곳 / 물어볼 것 (AI Hub 고객센터 또는 안심존 이용 안내)
1. 안심존 원격 환경에서 사용자 스크립트(Python) 업로드·실행이 되는지
2. 학습용 GPU/CPU 자원 제공 여부와 사용 시간 제한
3. 결과물 반출 범위: 통계 CSV / 모델 가중치 / 둘 다 불가
4. 졸업작품(비영리 교육 목적) 이용 시 별도 신청서 필요 여부
5. 해외 서버 사용 제한 범위 (기존 정책: 해외 반출은 별도 협의)

→ 이 답을 받기 전에는 71392 를 **주력 학습 데이터로 확정하지 않는다.**
